# مهارة `arabic-rtl-mobile`

مهارة مخصصة لتحسين وبناء واجهات موبايل عربية تعمل بشكل `RTL` صحيح فعلا، وليس مجرد ترجمة نصوص.

هذه المهارة مناسبة عندما يكون المشروع واحدا من هذه الأنواع:

- `iOS native`: `SwiftUI` أو `UIKit`
- `Android native`: `Jetpack Compose` أو `Views/XML`
- `React Native`

## ماذا تفعل المهارة؟

المهارة تساعد Codex على:

- تحديد ما إذا كان التطبيق أو الشاشة يعملان فعلا في `RTL` من الجذر
- استخدام الاتجاهات المنطقية الصحيحة مثل `leading/trailing` و `start/end` بدل الاعتماد الأعمى على `left/right`
- تثبيت محاذاة النصوص العربية والبطاقات والصفوف
- ضبط الأسهم والأيقونات والـ controls ذات الاتجاه
- إجراء فحص بصري عملي بعد التنفيذ على كل شاشة متأثرة

## الفكرة الأساسية

إذا كانت الشاشة ترث `RTL` بالفعل، فالأولوية تكون لاستخدام المحاذاة المنطقية الخاصة بالإطار المستخدم، لا لإضافة override جديد أو قلب الاتجاه يدويا مرة ثانية.

قبل أي إصلاح تفصيلي للصفوف أو الأزرار:

1. ضع نصا عربيا بعرض كامل
2. افحص بصريا هل ظهر على الحافة العربية الصحيحة
3. لا تبدأ إصلاحات الصفوف قبل نجاح هذا الاختبار

المهارة تركز على النتيجة البصرية الصحيحة، لا على "تماثل الكود".

## متى تستخدمها؟

استخدمها عندما تكون لديك:

- شاشة عربية تبدو وكأن نصوصها بمحاذاة يسار
- صفوف فيها نص عربي وعنصر ثانوي مثل `Stepper` أو badge أو chevron
- سهم رجوع أو disclosure باتجاه خاطئ
- عناصر تعتمد على `left/right` وتنكسر عند العربية
- حاجة إلى مراجعة RTL لشاشة `iOS native` أو `Android native` أو `React Native`

## مثال استخدام

```text
Use $arabic-rtl-mobile to review this Arabic mobile screen in iOS native, Android native, or React Native and fix RTL layout, row composition, icons, and navigation direction.
```
